# Q 版吉祥物重绘 v2 计划(kawaii 正统手法)

## 1. Summary

调研 kawaii 吉祥物设计(kawaii-coloring 教程、chibi 星球角色、Duolingo/LINE Friends 手法)后结论:
当前版本"丑"的根因是**元素堆砌 + 眼睛做法反了**。本次按正统 kawaii 手法重绘 [EarthVisual.kt](file:///d:/Random%20city/app/src/main/java/com/randomcity/app/ui/components/EarthVisual.kt),单文件改动。

## 2. 调研结论(为什么现在丑)

| 原则(参考项目共识) | 当前实现的问题 |
|---|---|
| kawaii 眼 = **纯黑大眼 + 2~3 个白色高光点** | 做成了白底大眼 + 小瞳孔,观感诡异 |
| 少即是多:简单几何、干净画面 | 冰盖/云带/卫星/轨道/小脚全堆上,杂乱 |
| 五官集中、位置靠下(婴儿比例) | 眼睛偏上偏小 |
| 嘴鼻极简:小弧线或张嘴笑 | 微笑弧线太成熟 |
| 腮红是标配 | 有(保留) |

## 3. 重绘规格(以 globeRadius R = 0.82×半径 为基准)

### 砍掉(降噪)
卫星 + 轨道环、极地冰盖、云带、小脚、瞳孔双高光

### 保留/重做
- **球体**:柔和蓝渐变 + **2 片**圆润大陆(边缘:左上、右下),避开脸部
- **眼睛(核心)**:纯黑圆 `#1F2A3A`,直径 **0.30R**,中心 ±0.28R、y = -0.02R(中下聚拢);
  每眼 **2 个白色高光**:大点 0.055R(左上)、小点 0.028R(右下)——经典 kawaii 眼
- **嘴**:开心张嘴笑,半圆 "D" 形(宽 0.24R × 高 0.16R,y +0.14R,`drawArc 0°→180°` 填充 `#1F2A3A`)
- **腮红**:椭圆 0.20R × 0.12R,±0.50R,y +0.14R,`#F2A9A0` alpha 0.45
- **小手**:两片椭圆 0.15R × 0.09R,±0.92R,y +0.10R,`#6FAE94`;左手随浮动挥摆(±10°)
- **阴影**:地面椭圆随浮动缩放(保留)

### 动效(全部保留,克制)
- 浮动 2.2s 往返
- 眨眼 ~3.8s(纯黑眼压扁)
- 左手挥动(随浮动相位)
