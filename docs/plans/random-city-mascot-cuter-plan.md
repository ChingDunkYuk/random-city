# Q 版地球吉祥物萌系升级计划

## 1. Summary

将首页 [EarthVisual.kt](file:///d:/Random%20city/app/src/main/java/com/randomcity/app/ui/components/EarthVisual.kt) 的 Q 版地球升级为"全套最萌"吉祥物:更大的星星眼、珊瑚腮红、小手小脚、头顶环绕小卫星。保留现有动效(浮动 + 眨眼),新增卫星环绕动效。单文件改动。

## 2. Current State Analysis

当前实现(本会话刚完成):柔和蓝海洋 + 圆润大陆 + 白底双眼(瞳孔高光)+ 圆头微笑 + 上下浮动 + 周期眨眼。
萌度不足的原因:眼睛偏小且位置偏高(成人比例)、无腮红、无四肢、无配饰。

## 3. 设计决策(用户跳过提问,采用默认值)

| 决策 | 方案 |
|---|---|
| 萌系元素 | 全套:大眼+星星高光+腮红+小手小脚+环绕小卫星 |
| 腮红 | 柔和珊瑚 `#F2A9A0`,alpha 40%(低饱和,读起来是萌不是粉) |
| 五官比例 | 婴儿脸比例:眼睛更大、位置更低更聚拢、嘴巴小巧 |
| 动效 | 保留浮动/眨眼;新增卫星缓慢环绕(12s 一圈);小手随浮动微摆 |

## 4. 造型规格(以 globeRadius R = 0.82 × 半径 为基准)

- **眼睛**:双眼圆(非椭圆),直径 0.30R,中心间距 0.52R,纵坐标中心 -0.05R(偏低);瞳孔 0.13R 深蓝 `#1F3A5F` + 主高光 0.05R + 副高光小点(星星感)
- **腮红**:椭圆 0.22R × 0.13R,位于眼下方外侧(±0.52R, +0.16R),`#F2A9A0` alpha 0.4
- **嘴巴**:小巧圆头弧,宽 0.26R,位于 +0.20R,弧线描边 0.05R,圆头
- **小手**:两侧椭圆 0.16R × 0.10R,肤色用陆地绿 `#6FAE94`;右侧(视觉左)静止,左侧举起 30°(随浮动相位微摆 ±6°)
- **小脚**:底部两椭圆 0.18R × 0.09R,`#6FAE94`,位于球体底部 +0.78R,间距 0.30R(画在球体下层,露出半个)
- **小卫星**:半径 0.045R 白色小球 + 细轨道环(0.98R 描边,alpha 0.3),12s 匀速环绕一周

## 5. Proposed Changes

### [EarthVisual.kt](file:///d:/Random%20city/app/src/main/java/com/randomcity/app/ui/components/EarthVisual.kt)(整体重写)
- 大陆块位置微调,避开脸部区域
- 绘制顺序:小脚 → 球体(海洋/大陆/冰盖/云)→ 小手 → 脸(眼/瞳孔/高光/腮红/嘴)→ 卫星与轨道
- 动效:
  - `bob`(0→1,2200ms FastOutSlowInEasing,Reverse)——整体浮动,阴影反相缩放(保留)
  - `blink`(3800ms keyframes,末段压扁)——眨眼(保留,眼形改圆后同步)
  - `orbit`(0→360,12000ms Linear)——卫星角度
  - 举起的小手旋转角 = 30° + sin(bob × π) × 6°
